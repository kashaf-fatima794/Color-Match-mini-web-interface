# Colour Match Mini Web Interface

A web-based colour matching application that uses machine learning to suggest colours based on RGB values.

## Tech Stack

- Python
- Streamlit
- Pandas
- Scikit-learn

## Run Locally

```bash
pip install -r requirements.txt
streamlit run frontend.py
```
